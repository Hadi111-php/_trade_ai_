## دسترسی به داده

دادهٔ کامل (۱.۱۲ میلیون کندل، ~۹۰ مگابایت) **روی گوشی** است:
`data/json/*.json`

برای استفادهٔ دوباره، هیچ دانلودی لازم نیست:

```bash
bash run-auto.sh --source json --tag rerun
```

## اگر روزی دوباره دانلود شد

```bash
bash run-auto.sh --verify-archive
```

| خروجی | معنی |
|---|---|
| `identical` | همان پنجره، همان محتوا — داده دست‌نخورده |
| `changed` + کد خروج ۳ | **همان پنجره، محتوای متفاوت** ⇒ صرافی تاریخ را بازنویسی کرده |
| `moved` | پنجره غلتان شده؛ هش قابل مقایسه نیست |
| `missing` | آن نماد در یک طرف نیست |

> ⚠️ `changed` تنها حالتی است که باید نگرانش باشیم. آن‌وقت نتیجهٔ اجرای ۱ باید
> بازبینی شود، چون روی داده‌ای ساخته شده که دیگر وجود ندارد.
