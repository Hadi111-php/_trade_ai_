# 📱 اجرای اسکن خودکار روی گوشی (Termux)

این تنها کاری است که باید روی گوشی انجام دهید. کل فرایند خودکار است:
دانلود داده → ذخیره در JSON → تحلیل → گزارش.

---

## ۰) نصب یک‌باره (فقط بار اول)

Termux را از **F-Droid** نصب کنید (نسخهٔ Play Store قدیمی است و مشکل دارد).

```bash
pkg update -y && pkg install python git -y
```

بعد پروژه را بگیرید:

```bash
pkg install git -y
git clone https://github.com/Hadi111-php/_trade_ai_.git
cd _trade_ai_/my_project/apps/futures-mtf-lab
```

> هیچ `pip install` لازم نیست. تمام کد با کتابخانهٔ استاندارد پایتون نوشته شده.

---

## ۱) اجرا (یک دستور)

```bash
bash run-auto.sh
```

همین. پیش‌فرض: **۲۰ نماد، ۵ سال، تایم‌فریم 4h**.

مدت تقریبی روی گوشی متوسط: **۲۰ تا ۴۰ دقیقه** (بیشترش دانلود است).

### نکات مهم در طول اجرا

- 📱 **گوشی را روشن نگه دارید.** اگر Termux را ببندید، دانلود قطع می‌شود.
  (اگر `termux-api` نصب باشد، اسکریپت خودش `wake-lock` می‌زند تا گوشی نخوابد:
  `pkg install termux-api -y`)
- 🔌 به شارژ وصل کنید.
- 📶 وای‌فای بهتر از دادهٔ همراه است.
- ⛔ **اگر وسط کار قطع شد، نگران نباشید.** دوباره `bash run-auto.sh` بزنید؛
  داده‌های دانلودشده ذخیره شده‌اند و از همان‌جا ادامه می‌دهد.

### اگر Bybit فیلتر بود

اسکریپت اول شبکه را چک می‌کند و اگر در دسترس نبود، صریح می‌گوید. در آن صورت:

1. VPN/پروکسی را روشن کنید و دوباره اجرا کنید
2. یا اگر قبلاً داده گرفته‌اید، فقط تحلیل را دوباره اجرا کنید:
   ```bash
   bash run-auto.sh --source json
   ```

## ۲) چه چیزی برای من بفرستید

بعد از پایان، اسکریپت این‌ها را نشان می‌دهد:

| فایل | چیست |
|---|---|
| `results/auto_scan_<تاریخ>.md` | **گزارش خوانا** — این را بفرستید |
| `results/auto_scan_<تاریخ>.json` | **بستهٔ داده** — برای بازبینی دقیق |
| `results/auto_scan_<تاریخ>.zip` | هر دو در یک فایل (اگر zip نصب باشد) |

**کافی است همان دو فایل `.md` و `.json` را بفرستید.** بقیه لازم نیست.

برای اینکه فایل را از گوشی بیرون بیاورید:
- `pkg install termux-api` → سپس `termux-share results/auto_scan_*.md`
- یا از فایل‌منیجر اندروید مسیر زیر را باز کنید:
  `~/../usr/../home/…` ← ساده‌تر: در Termux بزنید `cp results/auto_scan_*.md /sdcard/Download/`

## ۳) گزینه‌های اختیاری

```bash
# سریع‌تر: فقط ۲ سال
bash run-auto.sh --days 730

# فقط چند نماد
bash run-auto.sh --symbols BTCUSDT ETHUSDT SOLUSDT

# تایم‌فریم روزانه (معاملات کمتر، تست سخت‌تر)
bash run-auto.sh --tf 1d

# فقط چک کردن دسترسی شبکه، بدون دانلود
python3 -m mtflab autoscan --probe-only

# تحلیل مجدد بدون دانلود (سریع، آفلاین)
bash run-auto.sh --source json
```

## ۴) قاعدهٔ پذیرش — از قبل تعیین شده

این قاعده **قبل از دیدن نتیجه** نوشته شده و بعد از دیدن نتیجه تغییر نمی‌کند.
یک نسخه فقط وقتی «قبول» است که **همهٔ** این‌ها را داشته باشد:

| شرط | حد |
|---|---|
| تعداد نماد با دادهٔ کافی | ≥ ۸ |
| نمادهای با PF>1 | ≥ ۶۰٪ |
| سال‌های مثبت | ≥ ۶۰٪ |
| میانهٔ PF | ≥ ۱.۰۵ |
| معناداری در برابر نسخهٔ پایه | p ≤ ۰.۱۰ |
| حداقل معامله | ≥ ۱۰۰ |

اگر هیچ نسخه‌ای قبول نشد، **این هم یک نتیجه است** — و همان را می‌نویسیم.
فهرست ۲۰ نماد هم داخل کد ثابت است تا بعد از دیدن نتیجه عوضش نکنیم.

| پیام | راه‌حل |
|---|---|
| `python3 نصب نیست` | `pkg install python -y` |
