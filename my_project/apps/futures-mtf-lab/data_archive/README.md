# بایگانی داده

اینجا **شناسنامهٔ داده** می‌نشیند، نه خود داده.

| فایل | حجم | چیست |
|---|---|---|
| `data_digest_<tag>.json` | ~۳۰۰ KB | هش هر فایل + هش محتوا + بازهٔ UTC + کندل ماهانه + بستهٔ روزانه + نمونهٔ کندل خام |
| `data_digest_<tag>.md` | ~۱۰ KB | همان، خوانا برای مرور |

## چرا دادهٔ کامل اینجا نیست؟

۲۰ نماد × ۷۳۰ روز × ۱۵ دقیقه ≈ **۹۰ مگابایت**. گیت برای این حجم ساخته نشده و
تاریخچهٔ ریپو را برای همیشه سنگین می‌کند. اما «چه داده‌ای داشتیم» فقط چند صد
کیلوبایت است.

## سه لایه

| لایه | کجا | چه چیزی |
|---|---|---|
| ۱ | **همین پوشه (گیت)** | شناسنامه + هش‌ها + نمای ماهانه/روزانه |
| ۲ | گوشی | `data/json/*.json` — دادهٔ کامل (در `.gitignore`) |
| ۳ | اختیاری | `tar -czf data_<tag>.tar.gz data/json` برای GitHub Release |

## دستورها

```bash
bash run-auto.sh --archive --tag 15m-2026-10-31   # ساخت شناسنامه
bash run-auto.sh --data-index                      # فهرست بسته‌های موجود
bash run-auto.sh --data-index --deep               # بازبینی هش فایل‌ها
```

## قاعده

اگر روزی همان بازه دوباره دانلود شد، `content_sha256` باید **یکی** باشد.
اگر نبود ⇒ دادهٔ منبع عوض شده؛ نتیجهٔ قبلی باید بازبینی شود.
