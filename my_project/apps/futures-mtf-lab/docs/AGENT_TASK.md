# وظیفه ایجنت: تکمیل سناریوی معاملاتی چندتایم‌فریمی

> این فایل همان `docs/AGENT_TASK.md` اسکلتِ پیوست است، با یک تفاوت: بندهای
> «قوانین کار» با واقعیت این مخزن هم‌راستا شده‌اند (برنچ و PR). اصلِ خواسته
> دست‌نخورده مانده تا سابقهٔ تصمیم‌ها قابل ردیابی باشد.

## وضعیت پایه (از قبل پیاده‌سازی و تست‌شده — تغییر ندهید مگر باگ واقعی پیدا کنید)
| ماژول | نقش |
|---|---|
| `mtflab/bybit_public.py` | دریافت دادهٔ عمومی OHLCV از Bybit (بدون API key) + صفحه‌بندی + کش |
| `mtflab/alignment.py` | هم‌ترازی چندتایم‌فریمی بدون lookahead (با `bisect`) |
| `mtflab/fees.py` | محاسبهٔ کارمزد/اسلیپیج + فیلتر اقتصادی هزینه |
| `tests/test_alignment.py` | تست واحد ضد lookahead |
| `config/default_config.json` | کانفیگ پایه (به‌جای YAML → JSON، بدون وابستگی) |

## کاری که باید انجام شود
روی پایهٔ بالا، منطق استراتژی پیاده شد. **توابع حساس بالا بازنویسی نشدند**؛
فقط دو فیلد ایندکس (`higher_idx`/`bias_idx`) به `AlignedBar` اضافه شد تا موتور
بدون جست‌وجوی مجدد آرایه‌های اندیکاتور را ایندکس بزند (امضاها تغییر نکرد،
تست‌های اصلی بدون تغییر پاس می‌شوند).

### زمینه
- زبان: Python — **فقط کتابخانهٔ استاندارد** (بدون requests/pandas/numpy/pyyaml/pytest)
- داده: کندل‌های OHLCV عمومی از Bybit (بدون API key) برای BTCUSDT و ETHUSDT
- موتور بک‌تست: اختصاصی (بدون کتابخانهٔ آماده)
- کارمزد: 5.5bps هر طرف، اسلیپیج 0.02% (طبق `config/default_config.json`)

### خواستهٔ اصلی
یک سناریوی معاملاتی **قانون‌محور** (بدون ML، بدون LLM، بدون پارامتر پنهان) که:
- تایم‌فریم ۱ ساعت نقش «فیلتر رژیم/جهت» دارد
- تایم‌فریم ۱۵ دقیقه نقش «تریگر ورود» دارد
- لایهٔ اختیاری بایاس از ۴ ساعت (ارزش افزوده‌اش مستند شده)
- فقط از کندل‌های بسته‌شده استفاده شود (`alignment.py`)

### محدودیت‌های اجباری
1. هیچ‌جا از دادهٔ آینده استفاده نشود (از `align_multi_timeframe` استفاده شده و دور زده نشده)
2. دادهٔ گم‌شده/وقفه مدیریت شود، بدون forward-fill کورکورانه
3. از `fees.py` برای هزینه و فیلتر هزینه استفاده شود
4. تمام پارامترها در کانفیگ با مقدار پیش‌فرض مشخص
5. مدیریت ریسک: اندازهٔ پوزیشن، SL/TP، حداکثر معاملهٔ همزمان، کول‌داون بعد از ضرر

## قوانین کار (هم‌راستاشده با این مخزن)
1. کار روی برنچ `arena/444f3300-trade-ai` (قانون نشست) — **push مستقیم به main ممنوع**.
2. در پایان یک Pull Request باز می‌شود و **merge نمی‌شود** — بازبینی انسانی لازم است.
3. قبل از هر commit: `python3 tests/run_tests.py` و `python3 -m mtflab selftest` سبز باشند.
4. هیچ API key یا secret در کد/کانفیگ قرار نگیرد (داده عمومی است؛ اصلاً نیاز نیست).
5. هیچ فایلی از `apps/futures-scalp-lab` (سناریوی قدیم) تغییر نکند؛ اتصال فقط
   از طریق `mtflab/compare.py` و به‌صورت فقط‌خواندنی است.
