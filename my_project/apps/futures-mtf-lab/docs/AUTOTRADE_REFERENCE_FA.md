# مرجع اتوترید مجازی — تنظیماتی که نباید بی‌صدا عوض شوند

> **قاعدهٔ طلایی:** هر الگویی که بعداً کشف شد، فقط وقتی معتبر است که با **همین
> بستهٔ داده** و **همین تنظیمات** آزموده شده باشد. اگر چیزی عوض شد، آن یک
> «اجرای جدید» است، نه ادامهٔ همان یافته — و باید هش دادهٔ جدید ثبت شود.
> بدون این قاعده، هر یافته را می‌شود با عوض‌کردن یک پارامتر «تأیید» کرد و
> چیزی که به دست می‌آید علم نیست.

نسخه: ۱ · تاریخ: ۲۰۲۶-۱۰-۳۱ · شاخه: `arena/444f3300-trade-ai`

## ۱) دادهٔ مرجع

| قلم | مقدار |
|---|---|
| منبع | API عمومی Bybit v5 (`/v5/market/kline`) — بدون کلید، بدون حساب |
| نمادها | همان ۲۰ نماد ثابت در `mtflab/autoscan.py` (`DEFAULT_SYMBOLS`) |
| تایم‌فریم تریگر | `15m` |
| لایهٔ فیلتر | `1h` |
| لایهٔ بایاس | `4h` |
| بازه | ۷۳۰ روز (~۷۰٬۰۸۰ کندل در نماد) |
| منطقهٔ زمانی | **UTC** — همهٔ زمان‌ها epoch میلی‌ثانیه |
| ذخیره | `data/json/{symbol}_{tf}.json` + فهرست `data/json/_index.json` |
| شناسنامه | `results/data_digest_<tag>.json` (هش فایل + هش محتوا + بازه) |

**هیچ منبع دومی برای داده استفاده نمی‌شود.** مقایسه با آرشیو بیرونی (Binance و
مشابه) رد شد: مسیر، همان مسیر خودمان است و اعتبار از **هش** می‌آید، نه از منبع
دیگر. اگر روزی خواستیم صحت را بسنجیم، `content_sha256` را با دانلود دوبارهٔ
همان بازه مقایسه می‌کنیم.

## ۲) قرارداد زمان — قطعی و آزمایش‌شده

| موضوع | قاعده | تست قفل‌کننده |
|---|---|---|
| واحد زمان | epoch **میلی‌ثانیه** (ورودی s/µs/ns خودکار تبدیل می‌شود) | `test_epoch_units_are_normalised` |
| مرز کندل | `floor(ts / tf_ms) * tf_ms` — همیشه UTC | `test_hourly_buckets_start_on_the_hour` |
| کندل روزانه | دقیقاً ۰۰:۰۰ UTC، نه نیمه‌شب محلی | `test_daily_buckets_start_at_utc_midnight` |
| «سال مثبت» | سال تقویمی **UTC** | `test_engine_results_are_identical_in_any_local_timezone` |
| استقلال از منطقه | UTC / تهران / نیویورک / کلکته ⇒ خروجی **بیت‌به‌بیت یکی** | همان |
| تاریخ متنی | رد با خطا (منطقهٔ زمانی ندارد) | `test_csv_with_textual_dates_fails_loudly` |

**نتیجه:** تایم‌فریم روی نتیجه اثر **قطعی** دارد (تعداد کندل، هزینه، تعداد
معامله)؛ منطقهٔ زمانیِ گوشی اثر **صفر** دارد. هر وقت خواستیم نتیجه را با اجرای
قبلی مقایسه کنیم، فقط تایم‌فریم و بازه باید یکی باشند.

```bash

```

سپس: `results/data_digest_<tag>.json` و `results/auto_scan_<tag>.json` بایگانی

اگر نبود ⇒ دادهٔ منبع عوض شده و نتیجهٔ قبلی باید بازبینی شود.

## ۷.۵) ⚠️ درسی که گران تمام شد: هزینه با تایم‌فریم مقیاس می‌گیرد

هر معامله در ۱۵ دقیقه **۳.۷ برابر** ۴ ساعته هزینه دارد، نه فقط به‌خاطر تعداد
بیشتر، بلکه به‌خاطر **پوزیشن بزرگ‌تر**: حد ضرر ۱.۵×ATR در تایم‌فریم ریزتر،
قدر مطلق کوچک‌تری دارد ⇒ برای همان ریسک ۱٪، پوزیشن بزرگ‌تر می‌شود.

| | ۴h | ۱۵m |
|---|---:|---:|
| پوزیشن (notional) | ۲۷۵$ | ۱٬۰۱۶$ |
| کارمزد هر معامله | ۰.۳۰$ | ۱.۱۲$ |
| بار هزینه در سال | ۰.۷٪ | **۴۴.۱٪** |

**قاعدهٔ جدید پیش از هر تایم‌فریم تازه:** اول حساب کن
`معامله/سال × (کارمزد+اسلیپیج)/سرمایه` چقدر می‌شود. اگر بالای ۵٪ سال بود،
آن تایم‌فریم با اجرای تیکر عملاً بسته است — مهم نیست اندیکاتور چه می‌گوید.

## ۸) قاعدهٔ «الگوی جدید»

اگر الگویی پیدا شد:

1. با **همین بستهٔ داده** و **همین پارامترها** آزموده شود (نه با تنظیمات تازه).
2. اگر جواب مثبت بود، پارامترها **قفل** می‌شوند و در جدول ۳ ثبت می‌شوند.
3. اگر لازم شد پارامتری عوض شود، یک «اجرای جدید» با شناسنامهٔ جدید است؛ نتیجهٔ
   قبلی باطل نمی‌شود ولی با هم جمع هم نمی‌شوند.
4. هیچ الگویی فقط بر اساس **یک** پنجرهٔ زمانی تأیید نمی‌شود.
