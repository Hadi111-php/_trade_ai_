# یادداشت ردیابی: از فایل پیوست تا این اپ — چه چیزی تغییر کرد و چرا

فایل پیوست (`سناریوی ترید جدید کلود سونیت 1.txt`) یک اسکریپت bash به نام
`create_agent_task.sh` بود که **اسکلت** پروژه را می‌ساخت و یک پرامپت وظیفه برای
ایجنت می‌نوشت. آن اسکریپت **اجرا نشد** (چون فایل‌ها را در ریشهٔ ریپو و روی
برنچ `feature/mtf-strategy-design` می‌ساخت و با چیدمان `my_project/apps/…`
تداخل می‌کرد). محتوایش دستی و آگاهانه به این اپ منتقل شد.

## ۱) کدهایی که عیناً (یا با کمترین تغییر) منتقل شدند

| در فایل پیوست | در این اپ | تغییر |
|---|---|---|
| `src/backtest/alignment.py` | `mtflab/alignment.py` | امضاها و منطق یکسان؛ `higher_idx`/`bias_idx`/`low_idx` اضافه شد؛ `leakage_audit`, `alignment_coverage`, `get_last_closed_index` اضافه شد |
| `src/backtest/fees.py` | `mtflab/fees.py` | همان `FeeConfig`/`round_trip_cost_pct`/`passes_cost_filter` + چند هلپر (`from_bps`, `edge_ratio`, `slip_price`, `fee_on_notional`) |
| `tests/test_alignment.py` | `tests/test_alignment.py` | ۴ تست اصلی بدون تغییر + ۴ تست جدید (مرز بسته‌شدن، بایاس مستقل، حسابرسی نشتی، پوشش) |
| `config/default_config.yaml` | `config/default_config.json` | YAML → JSON (حذف وابستگی `pyyaml`)؛ همان مقادیر + بخش‌های `layers`/`scores`/`validation` |
| `docs/AGENT_TASK.md` | `docs/AGENT_TASK.md` | متن خواسته‌ها حفظ شد؛ فقط بند برنچ/PR با قانون این مخزن هم‌راستا شد |

## ۲) تغییرهایی که آگاهانه انجام شد (با دلیل)

| # | تغییر | دلیل |
|---|---|---|
| 1 | حذف property `Candle.is_closed_relative_to` | در اسکلت فقط `raise NotImplementedError` می‌داد: کد مرده و گمراه‌کننده. منطق «بسته بودن» در `drop_forming_candle` + شرط `alignment` صریح شد |
| 2 | `requests` → `urllib.request` | فقط کتابخانهٔ استاندارد؛ اجرای بدون pip روی Termux/گوشی/VPS (سیاست کل مخزن) |
| 3 | افزودن **صفحه‌بندی** به `fetch_klines_range` | یک درخواست Bybit حداکثر ۱۰۰۰ کندل می‌دهد؛ یک سال 15m ≈ ۳۵٬۰۰۰ کندل است. اسکلت فقط یک درخواست می‌زد |
| 4 | افزودن کش CSV + retry با backoff | اجرای تکراری نباید به شبکه وابسته باشد؛ نرخ خطای شبکه در تست‌های واقعی محسوس است |
| 5 | `pandas/numpy/pyyaml/pytest` → **حذف کامل** | هیچ‌کدام در سندباکس نصب نبودند؛ و کل سیستم موجود stdlib است. تست‌ها با `tests/run_tests.py` اجرا می‌شوند (و با pytest هم سازگارند) |
| 6 | مسیرها: `src/` در ریشه → پکیج `mtflab/` داخل اپ | جلوگیری از تداخل با `my_project/apps/*` و نگه‌داشتن دو سناریو کاملاً مستقل |
| 7 | برنچ `feature/mtf-strategy-design` → `arena/444f3300-trade-ai` | قانون نشست؛ نتیجهٔ عملی همان است: PR باز می‌شود و merge نمی‌شود |
| 8 | `alignment_version: "A"` در YAML → نسخه‌های A/B/C **کدِ واقعی** | در اسکلت فقط یک رشتهٔ کانفیگ بود؛ اینجا سه استراتژی قابل اجرا و مقایسه است |
| 9 | افزودن `resample_up` | اسکلت فرض می‌کرد هر سه تایم‌فریم جدا دانلود می‌شوند. برای مقایسهٔ «دادهٔ یکسان» روی CSV موجود، resample به بالا لازم بود (فقط به بالا، با حذف bucket ناقص) |
| 10 | افزودن داشبورد تب‌دار + compare | خواستهٔ شما در همین گفتگو (مقایسهٔ دو سناریو در تب‌های جداگانه) |

## ۳) چیزهایی که از اسکلت **حفظ** شدند چون درست بودند

- قانون طلایی هم‌ترازی: `higher_close_time ≤ trigger_open_time`
- استفاده از `bisect` برای هم‌ترازی O(log n)
- ممنوعیت forward-fill کورکورانه (`None` به‌جای مقدار جعلی)
- فیلتر هزینه با ضریب ۱.۵ برابر هزینهٔ رفت‌وبرگشت
- محافظه‌کارانه‌ترین فرض کارمزد: taker در هر دو طرف
- اصل «قبل از commit تست‌ها سبز باشند» و «هیچ API key در کد/کانفیگ نباشد»

## ۴) چیزهایی که اسکلت می‌خواست ولی **قابل اجرا نبود** در این محیط

| خواستهٔ اسکلت | مانع | راه‌حل |
|---|---|---|
| بک‌تست 15m از Bybit | سندباکس به `api.bybit.com` دسترسی ندارد و دادهٔ 15m در ریپو نیست | دانلودر آماده است؛ برای مقایسهٔ امروز از 1h/4h/1d (resample به بالا) استفاده شد و صریح برچسب خورد |
| `pytest tests/` | pytest نصب نیست | `tests/run_tests.py` (سازگار با pytest) |
| برنچ اختصاصی + PR بدون merge | قانون نشست | برنچ نشست + PR بدون merge |

## ۵) اگر خودت خواستی اسکریپت اصلی را اجرا کنی
