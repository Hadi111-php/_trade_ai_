اتوترید واقعی فیوچرز

این تب همیشه OFF شروع می‌شود و فعال‌سازی آن فقط با اقدام صریح تو و عبارت تأیید انجام می‌شود. مقصد قابل انتخاب LBank Futures یا Bitunix Futures است؛ فعلاً PWA فقط payload استاندارد را به Backend می‌فرستد. کلید API/Secret نباید داخل Browser/PWA ذخیره شود؛ Backend باید امضا و دسترسی Trade را مدیریت کند.

  • داده Mock هرگز اجازه ارسال واقعی ندارد؛ Real فقط با برچسب BYBIT LIVE مجاز است.
  • اتصال مستقیم LBank/Bitunix داخل Browser نیست؛ Adapter و امضای API باید روی Backend امن تو باشد.
  • API Key فقط دسترسی Trade داشته باشد و Withdraw خاموش باشد.
  • Kill Switch ارسال‌های بعدی را متوقف می‌کند؛ Backend باید سمت خودش هم Kill Switch و سقف ریسک داشته باشد.
  • مسیر داخلی /api/lbank/order در این محیط فقط DRY_RUN_ONLY است و سفارش صرافی ارسال نمی‌کند.
